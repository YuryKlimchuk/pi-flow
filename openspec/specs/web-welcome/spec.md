# web-welcome Specification

## Purpose
Предоставляет минимальный веб-интерфейс: приложение запускается как веб-сервер и отображает приветственную страницу через Thymeleaf.

## Requirements

### Requirement: Приложение запускается как веб-сервер

Приложение SHALL запускаться как веб-сервер Spring Boot, обслуживающий HTTP-запросы и не завершающийся сразу после запуска.

#### Scenario: Запуск сервера

- **WHEN** приложение запускается
- **THEN** веб-сервер стартует и продолжает обслуживать запросы

### Requirement: Приветственная страница доступна по корневому пути

Модуль `web` SHALL предоставлять приветственную страницу по корневому пути (`/`), отображаемую через Thymeleaf.

#### Scenario: Открытие главной страницы

- **WHEN** пользователь обращается по `GET /`
- **THEN** возвращается приветственная страница с кодом 200

### Requirement: Шаблоны используют Thymeleaf

Веб-представления SHALL формироваться шаблонизатором Thymeleaf.

#### Scenario: Рендеринг шаблона

- **WHEN** выполняется рендеринг приветственной страницы
- **THEN** используется Thymeleaf-шаблон из каталога шаблонов
