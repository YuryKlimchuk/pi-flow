# web-github-configuration Specification

## Purpose
Обеспечивает безопасное использование локального GitHub PAT и отображение состояния подключения без раскрытия секрета пользователю или диагностике.

## Requirements

### Requirement: Источник PAT
Приложение SHALL получать PAT через свойство `github.api.token`, значение которого по умолчанию берётся из переменной окружения `GITHUB_PI_FLOW_TOKEN` или локальной конфигурации вне Git.

#### Scenario: Локальный запуск
- **WHEN** задан `GITHUB_PI_FLOW_TOKEN` и приложение запущено
- **THEN** модуль github получает токен через `github.api.token`, а web не читает токен отдельным способом

### Requirement: Проверка конфигурации
Web SHALL проверять наличие и пригодность PAT только через вызов публичного контракта `github.api`.

#### Scenario: Токен отсутствует
- **WHEN** пользователь открывает функцию GitHub при пустом `github.api.token`
- **THEN** UI показывает состояние «токен не настроен» и не выполняет прямую проверку токена в web

### Requirement: Безопасность PAT
Web SHALL NOT включать значение PAT в HTML, URL, логи или текст сообщения об ошибке.

#### Scenario: Ошибка GitHub
- **WHEN** github выбрасывает ошибку конфигурации или аутентификации
- **THEN** отображаемый текст содержит только безопасное описание причины и не содержит значение PAT

### Requirement: Состояние подключения
Web SHALL отображать различимые состояния настроенного и недоступного подключения к GitHub на основании результата публичной операции или `GithubException.ErrorType`.

#### Scenario: Успешная проверка
- **WHEN** публичная операция github возвращает результат
- **THEN** страница показывает, что GitHub доступен
