# workspace-branches Specification

## Purpose
Определяет рабочие ветки Workflow и ограниченный набор локальных Git-операций, обеспечивающий изоляцию работы при использовании общей копии репозитория.

## Requirements

### Requirement: Именование ветки
Workspace SHALL именовать рабочую ветку по шаблону `pi-flow/{workflowId}` после валидации идентификатора Workflow.

#### Scenario: Валидный Workflow
- **WHEN** идентификатор равен `WF-42`
- **THEN** вычисленное имя ветки равно `pi-flow/WF-42`

### Requirement: Создание ветки
Workspace SHALL создавать рабочую ветку от целевой ветки, если рабочая ветка отсутствует.

#### Scenario: Ветка отсутствует
- **WHEN** целевая ветка существует, а `pi-flow/{workflowId}` отсутствует
- **THEN** рабочая ветка создаётся с базой на целевой ветке

### Requirement: Существующая ветка
Workspace SHALL повторно использовать существующую рабочую ветку только при проверяемом соответствии репозиторию.

#### Scenario: Ветка существует
- **WHEN** рабочая ветка уже есть в локальной копии
- **THEN** workspace переключается на неё и возвращает её состояние без создания дубликата

### Requirement: Переключение и состояние
Workspace SHALL переключать рабочую копию на нужную ветку и возвращать фактическое имя ветки и состояние дерева.

#### Scenario: Переключение
- **WHEN** запрошена валидная рабочая ветка в чистой копии
- **THEN** текущая ветка совпадает с запросом, а результат содержит состояние дерева

### Requirement: Локальные Git-операции
Публичный API workspace SHALL предоставлять вызывающим модулям только локальные операции ветки и коммита, не операции GitHub API.

#### Scenario: Коммит артефакта
- **WHEN** вызывающая сторона передаёт пути версионируемых артефактов и сообщение
- **THEN** workspace выполняет локальный коммит либо возвращает типизированную ошибку Git

### Requirement: Ошибки Git
Workspace SHALL преобразовывать ошибки создания, переключения и коммита в типизированную публичную ошибку Git.

#### Scenario: Конфликт переключения
- **WHEN** Git не может переключить ветку из-за состояния рабочей копии
- **THEN** возвращается ошибка Git, а текущие файлы не удаляются автоматически
