# web-repositories Specification

## Purpose
Позволяет пользователю просматривать репозитории, доступные PAT, и переходить из выбранного репозитория к его Issues через публичный контракт github.

## Requirements

### Requirement: Получение репозиториев
Web SHALL получать репозитории только вызовом `github.api.RepositoryOperations.listRepositories(PageRequest)`.

#### Scenario: Загрузка страницы
- **WHEN** пользователь открывает страницу репозиториев с номером страницы и размером
- **THEN** web передаёт эти параметры как `PageRequest` и использует возвращённый `RepositoryPage`

### Requirement: Отображение репозиториев
Страница репозиториев SHALL отображать имя и владельца каждого `RepositorySummary`.

#### Scenario: Непустой список
- **WHEN** github возвращает репозитории
- **THEN** HTML содержит owner/name каждого элемента и ссылку к его Issues

### Requirement: Пустой результат
Страница репозиториев SHALL отображать отдельное сообщение, если `RepositoryPage.items` пуст.

#### Scenario: Нет доступных репозиториев
- **WHEN** github возвращает пустой список
- **THEN** пользователь видит сообщение об отсутствии доступных репозиториев, а не пустую таблицу без пояснения

### Requirement: Ошибка доступа
Web SHALL отображать безопасное сообщение при ошибке загрузки репозиториев и SHALL NOT показывать stack trace или PAT.

#### Scenario: Недостаточные права
- **WHEN** `RepositoryOperations` выбрасывает `GithubException`
- **THEN** страница сообщает о недоступности данных и сохраняет ссылку для повторного запроса

### Requirement: Пагинация репозиториев
Если `RepositoryPage.hasNext` равен true, страница SHALL показывать ссылку на следующую страницу; при page > 1 SHALL показывать ссылку на предыдущую.

#### Scenario: Следующая страница
- **WHEN** github возвращает `hasNext=true`
- **THEN** ссылка next содержит увеличенный номер страницы и сохраняет размер страницы
