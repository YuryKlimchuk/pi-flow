# Spec Delta

## Purpose

Предоставляет пользователю наблюдаемое состояние Analyst, текст результата анализа, предложенное имя ветки и управляемый переход к следующему шагу без открытия Temporal UI.

## ADDED Requirements

### Requirement: Наблюдение анализа
Web SHALL периодически запрашивать публичное состояние запущенного workflow и показывать индикатор выполнения Analyst до получения терминального результата.

#### Scenario: Анализ выполняется
- **WHEN** публичное состояние workflow имеет статус `RUNNING` и этап `ANALYZING_REQUIREMENTS`
- **THEN** страница показывает индикатор «анализ выполняется» и продолжает обновление состояния без перехода в Temporal UI

#### Scenario: Ошибка анализа
- **WHEN** состояние workflow становится `FAILED`
- **THEN** страница показывает сообщение об ошибке и не показывает результат анализа как успешный

### Requirement: Отображение результата
Web SHALL отображать полный текст непустого артефакта `.pi-flow/analysis/analyst.md` после успешного завершения Analyst.

#### Scenario: Анализ завершён
- **WHEN** публичное состояние содержит успешный результат анализа и доступный текст артефакта
- **THEN** HTML страницы содержит текст артефакта без необходимости открывать workspace или Temporal UI

#### Scenario: Артефакт недоступен
- **WHEN** workflow завершил Analyst, но текст артефакта не может быть прочитан
- **THEN** страница показывает ошибку результата и не отображает кнопку продолжения

### Requirement: Предложенное имя ветки
Web SHALL показывать branch name, предложенный Analyst, отдельно от текста анализа.

#### Scenario: Валидное предложение
- **WHEN** результат содержит валидное латинское Git-имя ветки
- **THEN** страница отображает это имя как предложение Analyst

### Requirement: Продолжение workflow
Web SHALL предоставлять кнопку «Продолжить» только для успешного результата анализа с валидным branch name.

#### Scenario: Нажатие продолжения
- **WHEN** пользователь нажимает «Продолжить» на странице успешного анализа
- **THEN** web отправляет публичную команду продолжения для того же workflow и показывает состояние следующего этапа

#### Scenario: Продолжение недоступно
- **WHEN** анализ выполняется, завершился ошибкой или не содержит валидного branch name
- **THEN** кнопка «Продолжить» отсутствует или отключена и команда продолжения не отправляется
