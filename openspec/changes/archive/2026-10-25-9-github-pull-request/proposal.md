# Proposal

## Why

После `github-issues` модуль умеет читать контекст, но не завершает workflow публикацией результата. Этот change использует публичный контракт из `github-module-contract` и подключение из предыдущих changes для публикации подготовленной ветки и идемпотентного создания PR.

## What Changes

- Реализуется удалённая публикация уже подготовленной ветки без локального Git CLI или файловой системы.
- Вводится валидируемая команда PR с base, head, title и description.
- Реализуются поиск открытого PR, POST создания, возврат номера и абсолютного URL.
- Обрабатывается гонка 409/422 повторным поиском; закрытые PR не считаются открытыми.

## Capabilities

### New Capabilities
- `github-pull-request`: публикация ветки и идемпотентное создание PR.

### Modified Capabilities
- Нет.

## Impact

Затрагиваются операции публикации и PR в `github.application`/`github.infrastructure`. Change зависит от `github-issues` как последнего функционального предшественника и не переносит локальные Git-операции из `workspace`.
