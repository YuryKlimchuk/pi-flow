# Proposal

## Why

Без реализации подготовки публичный контракт workspace не создаёт и не приводит в актуальное состояние локальную копию. Change 19, опираясь на контракты 17 и конфигурацию 18, добавляет безопасные clone/update и выдачу подготовленного пути.

## What Changes

- Клонировать отсутствующий репозиторий в выбранную директорию.
- Обновлять существующую копию через fetch и безопасное приведение к целевой ветке.
- Не удалять незакоммиченные изменения автоматически.
- Обрабатывать повреждённые и неполные рабочие копии.
- Возвращать путь подготовленной директории через публичный контракт.

## Capabilities

### New Capabilities
- `workspace-preparation`: клонирование, безопасное обновление и проверка локальной копии.

### Modified Capabilities
- Нет.

## Impact

Изменяются application/domain порты и Git-инфраструктура workspace, определённые changes 17–18. GitHub API и бизнес-последовательность workflow не затрагиваются; ветки и блокировки детализируются в changes 20–21.
