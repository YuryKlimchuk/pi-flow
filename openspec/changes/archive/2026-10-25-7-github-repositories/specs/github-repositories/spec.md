# Spec Delta

## ADDED Requirements

### Requirement: Получение репозиториев
Публичная операция SHALL возвращать страницу доступных репозиториев с идентификатором, владельцем, именем и URL каждого элемента.

#### Scenario: Первая страница
- **WHEN** запрашивается страница `page=1` с заданным `perPage`
- **THEN** вызывается GitHub endpoint доступных репозиториев и результат содержит замаппленные элементы и метаданные страницы.

### Requirement: Пагинация репозиториев
Операция SHALL принимать `page` и `perPage`, а `hasNext` SHALL определяться по Link header GitHub либо по размеру ответа, если Link header отсутствует.

#### Scenario: Следующая страница отсутствует
- **WHEN** GitHub возвращает меньше элементов, чем `perPage`, и не возвращает ссылку `rel="next"`
- **THEN** результат содержит `hasNext=false`.

### Requirement: Валидация параметров страницы
Операция SHALL отклонять неположительный номер страницы и недопустимый размер страницы до HTTP-вызова.

#### Scenario: Некорректный page
- **WHEN** передан `page=0` или `perPage=0`
- **THEN** возвращается ошибка валидации и GitHub не получает запрос.

### Requirement: Ошибки получения репозиториев
Операция SHALL преобразовывать 401/403, 429, 5xx и timeout в типизированные ошибки с операцией, причиной, статусом при наличии и признаком повторяемости.

#### Scenario: Ограничение API
- **WHEN** GitHub возвращает 429
- **THEN** вызывающий получает retryable-ошибку получения репозиториев с HTTP-статусом 429.
