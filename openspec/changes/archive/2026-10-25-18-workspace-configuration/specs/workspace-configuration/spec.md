# Spec Delta

## Purpose

Определяет детерминированную конфигурацию размещения и предварительную проверку репозитория, чтобы подготовка workspace выбирала безопасный режим clone или update.

## ADDED Requirements

### Requirement: Базовая директория
Workspace SHALL принимать настроенную базовую директорию рабочих копий и SHALL отклонять её, если она не является доступной директорией файловой системы.

#### Scenario: Валидная база
- **WHEN** базовая директория существует и доступна для записи
- **THEN** workspace использует её как корень локальных копий

### Requirement: Валидация адреса
Workspace SHALL валидировать адрес репозитория до выполнения локальной Git-операции.

#### Scenario: Некорректный адрес
- **WHEN** адрес не соответствует поддерживаемому формату
- **THEN** workspace возвращает ошибку валидации и не создаёт директорию

### Requirement: Валидация ветки
Workspace SHALL валидировать имя целевой ветки до выполнения Git-операции.

#### Scenario: Запрещённое имя
- **WHEN** имя ветки содержит недопустимый Git-синтаксис
- **THEN** workspace возвращает ошибку валидации

### Requirement: Выбор режима
Workspace SHALL выбирать `clone` для отсутствующей локальной копии и `update` для существующей корректной копии.

#### Scenario: Локальная копия отсутствует
- **WHEN** вычисленный путь не существует
- **THEN** результат выбора содержит режим `clone`

#### Scenario: Локальная копия существует
- **WHEN** вычисленный путь содержит корректный репозиторий
- **THEN** результат выбора содержит режим `update`

### Requirement: Детерминированный путь
Workspace SHALL вычислять путь локальной копии из базовой директории, стабильного идентификатора репозитория и идентификатора Workflow без обхода за пределы базы.

#### Scenario: Повторный запрос
- **WHEN** два валидных запроса имеют одинаковые репозиторий и Workflow
- **THEN** они получают одинаковый путь

### Requirement: Ошибки доступа
Workspace SHALL различать ошибку доступа к репозиторию и ошибку доступа к файловой системе.

#### Scenario: Нет прав записи
- **WHEN** базовая директория недоступна для записи
- **THEN** возвращается ошибка файловой системы, а не ошибка Git-репозитория
