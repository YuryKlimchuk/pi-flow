# Proposal

## Why

MVP должен быть проверяемым без реального GitHub и не должен нарушать границы модулей. Change добавляет автоматические проверки поведения всех предыдущих changes и фиксирует запрет утечки PAT, прямого API и запуска Workflow.

## What Changes

- Покрыть маршруты, контроллеры, шаблоны репозиториев и Issues.
- Подменять `github.api.RepositoryOperations` и `IssueOperations` в тестах.
- Проверить отсутствие PAT в HTML, логах и сообщениях ошибок.
- Проверить архитектурные зависимости и отсутствие Workflow/Git/REST-логики в web.

## Capabilities

### New Capabilities
- `web-module-verification`: автоматическая проверка UI, ошибок, безопасности и архитектурных границ.

### Modified Capabilities
- Нет.

## Impact

Затрагивается тестовый код `web` и архитектурные проверки проекта; production-контракты не расширяются. Change зависит от 23–27 и является финальной проверкой MVP.
