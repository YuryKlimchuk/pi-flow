# Proposal

## Why

pi-flow — локальный оркестратор AI-агентов для автоматизации разработки ПО. Сейчас нет единого наглядного описания сквозного процесса, который проводит задачу разработки от подготовки репозитория до создания Pull Request через Pi Coding Agent с участием пользователя в контрольных точках. Без диаграммы процесса участникам трудно согласовать последовательность этапов, условия переходов, контрольные точки и обработку ошибок.

## What Changes

1. Создаётся диаграмма сквозного workflow разработки ПО (в формате Mermaid), описывающая:
   - последовательность этапов: `PREPARING_REPOSITORY`, `ANALYZING_REQUIREMENTS`, `DESIGNING_SOLUTION`, `IMPLEMENTING`, `REVIEWING`, `FINALIZING`;
   - жизненный цикл процесса с общими состояниями: `RUNNING`, `WAITING_FOR_USER`, `PAUSED`, `COMPLETED`, `FAILED`, `CANCELLED`;
   - контрольные точки взаимодействия с пользователем, циклы исправлений и повторных проверок;
   - обработку ошибок, приостановку, отмену и возобновление;
   - управление блокировкой репозитория и её освобождение;
   - условия успешного и неуспешного завершения.
2. Диаграмма становится отдельным файлом в корне каталога спецификаций (`openspec/specs/`) и остаётся единственным результатом данного изменения — без реализации кода.
3. Конечной точкой workflow является создание Pull Request; проверка, одобрение и слияние PR не входят в процесс.

## Capabilities

### New Capabilities

- `development-workflow`: наглядная диаграмма сквозного процесса разработки ПО — жизненный цикл workflow, этапы и переходы между ними, контрольные точки взаимодействия с пользователем, циклы исправлений и повторных проверок, обработка ошибок/приостановки/отмены/возобновления, управление блокировкой репозитория и условия завершения.

## Impact

1. **Документация процесса**: диаграмма workflow как единственный источник наглядного описания последовательности этапов, переходов и контрольных точек.
2. **Каталог спецификаций**: новый файл диаграммы в `openspec/specs/`.

Реализация кода, распределение этапов между доменной моделью и application-слоем с Temporal, а также интеграции с Pi/Git/GitHub/web на этом этапе НЕ выполняются.
