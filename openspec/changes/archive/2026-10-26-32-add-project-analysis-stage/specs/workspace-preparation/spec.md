# Spec Delta

## ADDED Requirements

### Requirement: Разрешение базовой ветки
Workspace SHALL определять базовую ветку для клонирования и обновления: если предпочтительная ветка существует в удалённом репозитории — использовать её, иначе, если существует `main`, использовать `main`.

#### Scenario: Предпочтительная ветка существует
- **WHEN** предпочтительная ветка `master` присутствует в удалённом репозитории
- **THEN** клонирование и обновление используют `master`

#### Scenario: Предпочтительная ветка отсутствует
- **WHEN** удалённый репозиторий не имеет `master`, но имеет `main`
- **THEN** клонирование и обновление используют `main`, а рабочая ветка `pi-flow/<workflowId>` создаётся от `main`
