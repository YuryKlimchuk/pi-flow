# Реализация решения

Реализуй задачу в рабочей директории и проверь результат сборкой и тестами.

## Порядок работы

1. Прочитай артефакты анализа и проектирования в `.pi-flow/`.
2. Внеси изменения в код, реализующие задачу.
3. Запусти сборку проекта.
4. Запусти тесты проекта.
5. Если сборка или тесты не прошли — исправь ошибки и повтори.

## Результат

Заверши работу с кодом 0, если сборка и тесты прошли, и с ненулевым кодом в противном случае. Диагностика сборки/тестов выводится в stdout/stderr.
