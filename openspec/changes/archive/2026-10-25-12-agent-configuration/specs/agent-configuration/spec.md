# Spec Delta

## Purpose

Определяет проверяемую подготовку безопасного запуска Pi с executable, аргументами, рабочей директорией и ограниченным окружением до создания процесса.

## ADDED Requirements

### Requirement: Конфигурация Pi
Модуль SHALL получать путь к исполняемому файлу Pi и общие параметры запуска из typed-конфигурации.

#### Scenario: Настроен executable
- **WHEN** конфигурация содержит путь к Pi и базовые параметры
- **THEN** подготовленный запуск использует эти значения без hard-coded shell-строки.

### Requirement: Безопасная команда
Модуль SHALL формировать команду как упорядоченный список executable и аргументов и SHALL NOT передавать пользовательский ввод через shell-конкатенацию.

#### Scenario: Аргумент со спецсимволами
- **WHEN** инструкция или параметр содержит пробелы, кавычки или `;`
- **THEN** значение остаётся одним argv-элементом и не выполняется как shell-команда.

### Requirement: Рабочая директория
Подготовка запуска SHALL отклонять путь, который отсутствует, не является каталогом или недоступен для чтения/исполнения.

#### Scenario: Валидный workspace
- **WHEN** передан существующий доступный каталог
- **THEN** подготовленная команда содержит его как рабочую директорию.

### Requirement: Безопасное окружение
Модуль SHALL передавать только разрешённые настройки окружения и SHALL NOT помещать значения секретных переменных в обычные логи или результат.

#### Scenario: Секрет в окружении
- **WHEN** запуск получает секретную переменную из разрешённого списка
- **THEN** Pi получает её значение, а диагностические данные содержат только имя или маскированное значение.

### Requirement: Недоступный Pi
Модуль SHALL возвращать типизированную ошибку подготовки или запуска, если executable Pi отсутствует, недоступен или не может быть запущен.

#### Scenario: Файл Pi отсутствует
- **WHEN** путь executable не существует
- **THEN** запуск завершается ошибкой до передачи задачи Pi.
