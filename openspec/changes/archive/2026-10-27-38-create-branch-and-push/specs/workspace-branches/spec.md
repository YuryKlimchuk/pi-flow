# Spec Delta

## MODIFIED Requirements

### Requirement: Создание ветки
Workspace SHALL создавать запрошенную итоговую ветку от текущей подготовленной базы, если ветка отсутствует, и SHALL возвращать фактическое имя ветки.

#### Scenario: Ветка отсутствует
- **WHEN** целевая ветка существует, а `pi-flow/{workflowId}` отсутствует
- **THEN** рабочая ветка создаётся с базой на целевой ветке
#### Scenario: Ветка Analyst отсутствует
- **WHEN** workflow передаёт валидное имя `feature/issue-42-login`, а такой ветки нет
- **THEN** workspace создаёт и переключает ветку с этим именем, не заменяя его на `pi-flow/{workflowId}`
#### Scenario: Ветка уже существует
- **WHEN** запрошенная итоговая ветка уже существует в рабочей копии того же workflow
- **THEN** workspace переключается на неё без создания дубликата и возвращает её имя

### Requirement: Локальные Git-операции
Публичный API workspace SHALL предоставлять вызывающим модулям операции создания итоговой ветки и локального коммита только перечисленных артефактов, не операции GitHub API.

#### Scenario: Коммит артефакта
- **WHEN** вызывающая сторона передаёт пути версионируемых артефактов и сообщение
- **THEN** workspace выполняет локальный коммит либо возвращает типизированную ошибку Git
#### Scenario: Коммит артефактов workflow
- **WHEN** вызывающая сторона передаёт пути `.pi-flow/analysis/analyst.md` и `.pi-flow/design/architect.md` и сообщение коммита
- **THEN** workspace выполняет локальный коммит на запрошенной ветке и возвращает commit id либо типизированную ошибку Git
