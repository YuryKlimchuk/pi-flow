# Proposal

## Why

Для ручного тестирования недостаточно успешных страниц: пользователь должен понимать загрузку, причину сбоя и способ повторить запрос. Change завершает поведение интерфейса из 23–26, не добавляя новую бизнес-логику.

## What Changes

- Показывать состояние загрузки и результат запроса.
- Сопоставлять `GithubException.ErrorType` с понятными сообщениями для configuration/authentication/rate-limit/network/server/not-found.
- Добавить повтор неудачного запроса и сохранить контекст выбранного репозитория.
- Обеспечить базовую адаптивность локальных страниц.

## Capabilities

### New Capabilities
- `web-ui-states`: состояния загрузки, ошибки, retry и контекст навигации.

### Modified Capabilities
- Нет.

## Impact

Затрагиваются контроллеры, обработка исключений и шаблоны `web`; GitHub-контракт используется без изменений. Change зависит от 23–26 и завершает сценарий MVP перед тестовым change 28.
