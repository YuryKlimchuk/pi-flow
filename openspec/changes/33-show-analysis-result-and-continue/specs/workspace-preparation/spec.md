# Spec Delta

## ADDED Requirements

### Requirement: Чтение артефакта анализа
Публичный контракт workspace SHALL предоставлять чтение ожидаемого артефакта анализа по workspace path и SHALL ограничивать чтение корнем соответствующего workspace.

#### Scenario: Артефакт существует
- **WHEN** вызывающая сторона запрашивает `.pi-flow/analysis/analyst.md` внутри подготовленного workspace
- **THEN** workspace возвращает его непустой текст и метаданные файла

#### Scenario: Путь вне workspace
- **WHEN** вызывающая сторона запрашивает путь, выходящий за корень workspace
- **THEN** workspace отклоняет запрос и не читает файл

#### Scenario: Файл отсутствует
- **WHEN** ожидаемый артефакт отсутствует или пуст
- **THEN** workspace возвращает типизированную ошибку чтения результата
