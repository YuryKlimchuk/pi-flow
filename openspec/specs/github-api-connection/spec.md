# github-api-connection Specification

## Purpose
Обеспечивает конфигурацию, аутентификацию и типизированную обработку ошибок подключения к GitHub API.

## Requirements

### Requirement: Конфигурация GitHub клиента
GitHub-клиент SHALL получать base URL, токен, connect timeout, read timeout и размер страницы из typed внешней конфигурации.

#### Scenario: Внешние свойства применены
- **WHEN** свойства GitHub заданы через Spring configuration
- **THEN** клиент использует заданный URL и тайм-ауты без значений, зашитых в исходном коде.

### Requirement: Авторизация запросов
Адаптер SHALL добавлять Authorization-заголовок к каждому запросу GitHub при наличии токена.

#### Scenario: Авторизованный запрос
- **WHEN** выполняется операция с настроенным токеном
- **THEN** mock HTTP server получает Authorization-заголовок, а токен не попадает в DTO или обычный лог.

### Requirement: Обязательный токен
GitHub-операция SHALL завершаться конфигурационной ошибкой до HTTP-вызова, если обязательный токен отсутствует.

#### Scenario: Нет токена
- **WHEN** вызывается операция без токена
- **THEN** возвращается конфигурационная ошибка и mock HTTP server не получает запрос.

### Requirement: Типизированные ошибки подключения
Адаптер SHALL классифицировать ответы 401/403, 404, 409/422, 429, 5xx и timeout в ошибки, содержащие операцию и статус или сетевую причину, без секретов.

#### Scenario: Повторяемая ошибка
- **WHEN** GitHub возвращает 429 или 5xx либо происходит timeout
- **THEN** вызывающий получает ошибку с признаком повторяемости и без Authorization-токена в сообщении.
