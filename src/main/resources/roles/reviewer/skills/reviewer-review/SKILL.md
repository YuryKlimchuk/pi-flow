# Ревью реализации

Выполни независимое ревью реализованного решения и верни результат текстом.

## Что проверять

1. Соответствие реализации Issue, анализу и proposal.
2. Корректность и полнота изменений.
3. Качество кода и потенциальные дефекты.
4. Покрытие тестами и прохождение сборки.

## Результат

Верни результат ревью текстом в stdout: найденные проблемы, замечания и рекомендации. Явно укажи, приемлемо ли решение.
