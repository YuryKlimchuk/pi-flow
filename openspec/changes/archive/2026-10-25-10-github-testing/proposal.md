# Proposal

## Why

После завершения функциональных changes 1–5 нужен отдельный проверочный контур, подтверждающий публичный контракт, REST-адаптер и архитектурные границы. Этот change использует все предыдущие изменения и не добавляет нового production-поведения: он делает реализацию проверяемой и завершает валидацию OpenSpec.

## What Changes

- Добавляются contract-тесты публичных портов для успехов, валидации и typed ошибок.
- Добавляются интеграционные тесты адаптера с локальным mock HTTP server.
- Усиливаются архитектурные проверки направлений зависимостей и отсутствия циклов.
- Выполняются полная компиляция, тесты и `openspec validate` для этого change.

## Capabilities

### New Capabilities
- `github-module-verification`: проверяемость публичного контракта, адаптера и архитектуры модуля.

### Modified Capabilities
- Нет.

## Impact

Затрагиваются только тестовые исходники, архитектурные проверки и контур сборки. Change последователен после `github-pull-request`; production-код добавляется только при необходимости исправить обнаруженное несоответствие контракту.
